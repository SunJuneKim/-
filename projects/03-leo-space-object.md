# 프로젝트 3: 저궤도 우주물체 (운영제어부)

## 개요

| 항목 | 내용 |
|------|------|
| **기간** | 2026.01 ~ 현재 |
| **역할** | 운영제어부 **1인 개발** |
| **성격** | NSLR(1과제)와 유사한 **저궤도(LEO)** 우주물체 추적 시스템 |

---

## 시스템 구성

- **구성품 7개**
- **카메라 3대** 전시·제어
- **조이스틱** 마운트 제어
- **Cesium** — 위성 궤도 추적·운영 UI

---

## 1과제(NSLR) 대비 차이

| 항목 | NSLR (1과제) | 저궤도 |
|------|--------------|--------|
| 통신 | TCP/UDP, 다구성품 동기화 | **UDP** |
| 시간 동기화 | **NTP/GPS ns급** (필수) | **불필요** |
| UI | WinForms | **WPF** |
| 궤도 | 천문 라이브러리 | **Cesium + TLE/SGP4** |
| 인원 | 명목 2명, 실질 단독 | **1인** |

---

## 담당 업무

- 운영제어부 애플리케이션 **1인** 설계·개발
- 7구성품 **UDP** 통신·상태 관리
- 3카메라 영상 전시·제어
- **Cesium** + **TLE/SGP4** 기반 저궤도 위성 궤도 시각화·추적
- 조이스틱 마운트 제어 UI

---

## 기술 스택

```
WPF, C#
UDP
Cesium, TLE, SGP4 (orbit propagation)
```
