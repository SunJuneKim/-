# 프로젝트: IRST (통신카드 대체)

> XMC HDLC 프로젝트의 정식 명칭. **NSLR과 별개 프로젝트.**

---

## 한 줄

상용 통신카드를 자체 FPGA 카드로 바꾸면서, **호환 레이어 + Linux 드라이버 + 검증용 앱**을 맡아 **70시간 연속 가동 검증 후 납품**.

---

## 개요

| 항목 | 내용 |
|------|------|
| **프로젝트명** | **IRST** |
| **기간** | 2025.10 ~ (납품 완료 구간 있음) |

| **목적** | tdrv009/002 상용 카드 → 자체 FPGA 카드, **유저 앱 무수정** |

---

## 기술 상세 (이력서·면접용)

### 통신 방식
| 채널 | 방식 |
|------|------|
| **RS422** 7ch | 기존이 tty 기반이라 **tty** 사용 |
| **HDLC** 1ch | **ioctl** |

### 드라이버 개선
- 기존 **FIFO** → **원형 큐(circular queue)** 로 변경
- **이슈 1:** HDLC 간헐적 **0 byte** 수신
- **이슈 2:** RS422 **데이터 분할 수신** (쪼개져 들어옴)
- 원형 큐로 **빈도는 감소**, 완전 제거는 못 함

### 앱 수정 불가 → 드라이버에서 처리
- 상위 **어플리케이션 수정 불가** 상황
- 드라이버에서 **패킷 파싱** — 헤더 **조건문**으로 프레임 처리
- 정석은 아니지만 **실장비 납품까지 마무리**

### 검증·납품
- **70시간 이상 연속 가동** 안정성 확인 후 납품

## 이력서 bullet (자연어)

- **IRST:** 상용→자체 FPGA 통신카드 교체. 호환 레이어·검증 앱 단독 개발
- RS422(tty) 7ch + HDLC(ioctl) 1ch. 드라이버 **FIFO→원형 큐** 전환
- HDLC 0byte·RS422 분할 수신 이슈 — 앱 수정 불가하여 **드라이버 패킷 파싱**으로 대응
- **70시간+ 연속 가동** 검증 후 납품
