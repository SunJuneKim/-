## 요구사항 변경 (경력기술서·면접용)

| 단계 | 내용 |
|------|------|
| **초기 안내** | 기존 **절차서**대로 진행하면 됨 |
| **절차서 한계** | **다중 채널 동시 통신** 절차 없음 |
| **실제 요구** | RS422 7ch + HDLC 1ch **동시 통신**, 채널별 **주기 상이** |
| **스펙 이슈** | 업체 앱 스펙 **늦음·불명확**, 초기 말과 **다름** → 재진행 |
| **결과** | 1차 납품 후 변경 반영, **6월까지** 수정·검증 |

> 면접 톤: 비난 없이 — *"초기 절차서와 실제 앱 스펙이 달라져서, 다중 채널·주기 조건으로 다시 맞췄습니다."*

## 기술 상세

### 통신
| 채널 | 방식 |
|------|------|
| RS422 7ch | **tty** (기존 tty 기반) |
| HDLC 1ch | **ioctl** |

### 드라이버
- **FIFO → 원형 큐**
- HDLC **0 byte** 간헐 수신
- RS422 **분할 수신** (쪼개짐)
- 앱 수정 불가 → 드라이버 **헤더 조건문 패킷 파싱**

### 검증
- **HIL** (베이스보드 장착 후)
- **70시간+ 연속 가동**
