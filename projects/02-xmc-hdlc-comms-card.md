# 프로젝트 2: IRST (통신카드 대체)

> **NSLR과 별개.** 상세: [`02-irst-comms-card.md`](02-irst-comms-card.md)

## 개요

| 항목 | 내용 |
|------|------|
| **기간** | 2025.10 ~ 현재 |
| **역할** | **호환 레이어·응용프로그램** 개발 → **드라이버 로직 수정** 진행 중 |
| **인원** | 2명 (명목) — **실질 단독 수행** |
| **동료 역할** | 기존 상용 드라이버 **코어** 개발에 과거 참여 (현재 본인이 주도) |
| **목적** | 상용 통신카드 → **자체 FPGA 통신카드** 대체 |

---

## 역할 분담 (실제)

| 영역 | 담당 |
|------|------|
| 기존 드라이버 **코어** | 동료 (과거 개발 참여, 기반 존재) |
| **호환 레이어** | **본인** |
| **응용 프로그램** (테스트·검증) | **본인** |
| **드라이버 로직 modify** | **본인** (현재 진행) |

> 이력서: *"기존 드라이버 코어 기반 위에 호환 레이어·응용 SW 구축, 현재 드라이버 로직 직접 수정 중"*

---

## 배경

- SBC CPU + 상용 통신카드, 기존 SW: **tdrv009**, **tdrv002**
- 자체 FPGA 카드 교체 시 **유저 애플리케이션 무수정** 목표

---

## 담당 업무

### 1. 호환 레이어 + 응용 SW (완료·운영)
- 상용·자체 **레지스터 맵·매뉴얼** 대조
- **호환 레이어** 구현
- PC 연동 **목업 테스트**, C#/Python/WinForms 검증 프로그램

### 2. 드라이버 로직 수정 (진행 중)
- HDLC **stash/split** 등 레거시 호환 이슈 대응
- 커널/드라이버 레벨 **로직 modify**

### 3. 통신 구성

| 채널 | 프로토콜 | 스펙 |
|------|----------|------|
| 7ch | RS422 | 200 byte @ 1 Hz |
| 1ch | HDLC | 50 byte @ 200 Hz |

### 4. 플랫폼
- 포트 변경, 디바이스 노드명, **SCC 리맵핑**

---

## 현재 이슈

| 이슈 | 상태 |
|------|------|
| HDLC 배치·미정렬 | 디버깅 중 |
| 자체 앱 + PC 앱 | **정상** |
| 업체 레거시 앱 | **NG** — stash/split 추정 |
| 드라이버 로직 modify | **진행 중** |

---

## 기술 스택

```
Linux C (driver modify)
Python, C#, WinForms (test apps)
FPGA 통신카드, SBC, RS422, HDLC
```

---

## 42dot 이력서용 bullet (확정 초안)

- 상용 통신카드(tdrv009/002) → 자체 FPGA 카드 대체: **호환 레이어·검증용 응용 SW 단독** 개발
- **RS422 7ch + HDLC 1ch**, HDLC 50B@200Hz / RS422 200B@1Hz 요구사항 대응
- 레거시 유저 앱 무수정 호환 (자체 앱); 업체 레거시 앱 **HDLC stash/split** 이슈 → **드라이버 로직 직접 수정** 중
- PC 연동 목업 테스트로 요구사항 변경 사이클 단축
