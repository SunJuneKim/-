# 프로젝트 1: 차세대 SLR 시스템 (NSLR)

## 개요

| 항목 | 내용 |
|------|------|
| **정식 명칭** | **NSLR** — 차세대 **SLR(Satellite Laser Ranging)** / 우주물체 **레이저 거리측정** |
| **IRST와 관계** | **별개 프로젝트** (IRST = 통신카드·드라이버) |
| **기간** | 2023.01 ~ 2025.10 (약 2년 10개월) |
| **역할** | 운영제어부 **시스템 로직 오너** (스케줄러 제외) + 스케줄러 **사수(기술 리드)** |
| **인원** | 2명 (명목) — **시스템 로직 실질 단독** |
| **소스** | GitHub NSLR 프로젝트 — [담당 범위 상세](01-nslr-code-ownership.md) |
| **고객/협력** | 한화시스템 (거창 현장, 평일 장기 상주) |
| **성격** | 위성 레이저 거리 측정·우주물체 추적 및 정밀 측정 시스템 |

## 프로젝트가 하는 일 (한 줄)

우주물체·위성을 지향해 **레이저를 쏘고 거리를 측정**하는 시스템.  
**지상보정**(시스템 딜레이), **별보정**(마운트·광학)을 거쳐 관측.  
본인 업무: **구성품 제어·동기화·운영제어 SW**.

---

## 현장·과제 맥락 (이력서 X)

- 과제 책임자도 시스템 설계 초안 — **맨땅에서 전원 출발**
- 운영제어부 담당으로 논문·자료 찾아가며 **자기주도 해결**
- 거리측정 **최종 성공은 과제 전체 이슈** (본인 판단: 운영제어부 밖 설계·타 모듈)
- jitter, 마운트 반환 지연, RGG(광학) 제어 등 **시스템 이슈 인지** — 상세는 `resume/work-style-notes.md`

## 본인 기여 범위

### 시스템 로직 — 100% 담당 (스케줄러 제외)
GitHub NSLR 소스 기준, **Scheduler 모듈을 제외한 운영제어부 시스템 로직 전반**이 본인 담당입니다.

### 스케줄러 — 동료 개발 + 본인 사수
| 항목 | 내용 |
|------|------|
| 구현 | 회사 동료 |
| 본인 | **사수** — 아키텍처·구성품 인터페이스·통합 기준 가이드, 연동 검증 |

### 100% 담당 (운영제어부 기준, 스케줄러 제외)
- **시간 동기화** (NTP/GPS, ns급 요구 대응) — 설계·구현·튜닝 전 과정
- **별보정(star calibration)** 운용 및 **로직 구현 전반**
- **이벤트 타이머** 제어
- **7개 구성품 + 3종 카메라** 연동·동기화·운영 로직
- **영상 파이프라인** (acquisition, OpenCV, AGC/ROI, overlay, 전시)
- **위성 트래킹** 시스템 로직
- **PostgreSQL** 운영 DB
- **한화시스템 담당자 포함** 협업·운영 조율
- **실장비 연동 디버깅**, **관측 운영** 전 과정

### 제외 (별도 담당 영역)
- **마운트 엔코더값 제어 정밀도** — 마운트부 하위 정밀 제어 루프 (본인 영역 아님)

> 이력서 표현: *"마운트 엔코더 서브루프를 제외한 운영제어부 전 모듈 단독 설계·구현·운영"*

## 현장 = 개발 중단이 아님 (핵심 어필)

거창 현장 2년 상주는 **유지보수만 한 기간이 아님**.

| 수행 내용 | 상세 |
|-----------|------|
| **구현** | 운영제어부 SW 지속 개발·개선 |
| **실장비 연동 디버깅** | 7구성품·3카메라 실시간 통합 |
| **관측 운영** | 실제 SLR 관측 미션 수행·대응 |
| **운영 시간** | 평일 오전 ~ 새벽 (한화시스템 협업) |

**면접 한 줄:**  
> "현장에 있었다고 코딩을 안 한 게 아니라, **구현·연동·디버깅·관측을 동시에** 버텼습니다."

## 담당 업무 (상세)

### 1. 실시간 통신·동기화
- 7개 구성품 + 3카메라 **실시간 통신 및 동기화 제어**
- **NTP 서버 + GPS** 기반 시간 동기화 (**본인 100%**)
- **ns(나노초)급** 동기화 요구 대응
- **이벤트 타이머** 제어
- **마운트 20ms** 제어 (운영 로직; 엔코더 정밀도 제외)
- 위성 **트래킹** 시스템 로직

### 2. 영상 시스템
- **MWIR / CCD / EMCCD** acquisition 및 전시
- 카메라 SDK, **OpenCV** (AGC, Mono8, ROI), overlay, thermal

### 3. 천문·보정
- **별보정** 운용·로직 **전반** (coefficient 수학적 이해·튜닝)
- 천문 라이브러리, 마운트 모델링용 calibration

### 4. 데이터·운영
- PostgreSQL, 대기환경 센서, 구성품 상태 전시
