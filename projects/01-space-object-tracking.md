# 프로젝트 1: 우주물체 1과제 (NSLR 시스템)

## 개요

| 항목 | 내용 |
|------|------|
| **기간** | 2023.01 ~ 2025.10 (약 2년 10개월) |
| **역할** | NSLR 시스템 **운영제어부** 개발 |
| **인원** | 2명 |
| **고객/협력** | 한화시스템 (거창 현장, 평일 장기 상주) |
| **성격** | 우주물체 추적 및 정밀 측정 시스템 |

---

## 시스템 아키텍처

운영제어부는 **PC 4대**로 구성:

| 부서 | 역할 |
|------|------|
| **관측제어부** | 관측 장비 제어 |
| **운영전시부** | 구성품 상태 전시, 대기환경모듈 센서 데이터 수신·관리·저장 |
| **데이터처리부** | 영상/측정 데이터 처리 |
| **데이터관리부** | 데이터 저장·관리 (PostgreSQL) |

**연동 구성**: 카메라 3대 + 기타 구성품 5개 = **총 8개 요소** (카메라+구성품 5 → 문맥상 6구성품+3카메라로도 기술)

---

## 담당 업무 (상세)

### 1. 실시간 통신·동기화
- 6개 구성품과 **실시간 통신 및 동기화 제어** 구현
- **NTP 서버 + GPS** 기반 시간 동기화
- **ns(나노초)급** 동기화 요구 대응
- **이벤트 타이머** 제어
- **마운트 20ms** 정밀 제어
- 위성 **트래킹** 시스템 로직 구현

### 2. 영상 시스템
- **MWIR / CCD / EMCCD** 카메라 영상 acquisition 및 전시
- 카메라 **SDK 연동**
- **OpenCV** 기반 preprocessing
- **AGC** (Automatic Gain Control)
- **Mono8** 변환
- **ROI** 기반 영상 처리
- Overlay 작업
- Thermal imaging 파이프라인

### 3. 천문·보정
- **마운트 모델링**을 위한 **별보정(star calibration)**
- 천문 라이브러리 활용
- 별보정 라이브러리 **파라미터·계수(coefficient)** 수학적 이해 및 튜닝
- calibration 모델 이해 → 실제 시스템 맞춤 수정

### 4. 데이터·운영
- **PostgreSQL** DB 관리
- 운영전시부: 구성품 상태 모니터링, 대기환경 센서 데이터 저장
- 시스템 운영 로직 전반

### 5. 현장
- **거창** 시설 설치·유지보수
- 한화시스템과 약 2년 협업 (평일, 오전~새벽 운영 대응)
- 현장 디버깅 및 **안정화**

## 42dot 이력서용 bullet (초안)

- 3년간 우주물체 추적·정밀측정 시스템의 **운영제어부** 설계·개발·현장 운영
- **3종 카메라(MWIR/CCD/EMCCD)** acquisition·전처리(AGC/ROI)·전시 파이프라인 구축
- **6개 구성품** 실시간 통신·**NTP/GPS ns급 동기화**·마운트 20ms 제어·위성 트래킹 로직 구현
- **별보정(calibration)** 파라미터 분석·최적화로 **50 arcsec 이하** 정밀도 달성 기여
- **4PC 분산 아키텍처**(관측/전시/처리/관리) 및 **PostgreSQL** 운영 데이터 관리
- 구조 변경 제약 하에서 **timing jitter** 최소화 튜닝으로 운영 안정성 확보
- 다수 협력사(한화시스템)와 **2년 현장 통합** — 설치·검증·유지보수

## 차별화 스토리 (면접)

### 시스템 오차를 구조적으로 본 경험
- ns급 정밀도에서 **네트워크 기반 timing 전달**이 측정에 미치는 영향 체감
- 아키텍처·일정 고정 → **구조 변경 대신 튜닝·보정**으로 대응한 trade-off 설명

### 라이브러리 수준을 넘는 개발
- coefficient 의미 파악, calibration 모델 이해, 현장 tuning
