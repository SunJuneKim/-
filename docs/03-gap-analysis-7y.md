## 복합 시스템 문제 사례 (면접용 — 초안)

> 아래는 질문지 답변 후 구체 수치로 보강할 예정

### 사례 1: 타이밍 jitter vs 아키텍처 고정
- **상황**: ns급 동기화 요구, NTP 기반 구조 이미 고정
- **문제**: 네트워크 지연으로 tracking 정밀도 변동
- **행동**: 구조 변경 대신 이벤트 타이머·보정 파라미터 튜닝, 구성품별 latency 측정
- **결과**: 50 arcsec 이하 달성 기여 (수치 확인 필요)

### 사례 2: HDLC 레거시 앱 호환 실패
- **상황**: 자체 테스트 앱 OK, 변경 불가 업체 앱 NG
- **가설**: HDLC stash/split 미구현
- **행동**: 프레임 덤프 비교, 상용 카드 vs 자체 카드 타이밍 분석 (진행 중)
- **시사점**: black-box 호환은 **스펙 문서 + 실측** 병행 필요

### 사례 3: 구성품 인터페이스 제약 흡수
- **상황**: 6개 구성품 각각 다른 프로토콜·타이밍
- **행동**: 운영제어부에서 동기화 오케스트레이션, 상태 전시·DB 저장 통합
- **시사점**: AD의 multi-ECU 통합과 동형

## 솔직한 커리어 조언

1. **42dot은 "연구형 CV"가 아니라 "시스템형 AD"로 가는 게 맞다**
2. **7년차**면 "무엇이든 했습니다"보다 **"이 문제는 내가 구조적으로 봤다"** 한 건이 필요 → 타이밍 jitter 사례가 좋음
3. **ROS2 4~8주** 투자 대비 합격 확률 상승이 가장 큼
4. 현재 HDLC 이슈 해결은 **이력서 한 줄**이 됨: *"Legacy HDLC framing compatibility under proprietary host application constraints"*
