## 경력 요약

**Linux 디바이스 드라이버와 실시간 다모듈 통합 SW**를 해온 선임 연구원입니다.

에너시스에서 **STM32 MCU·아날로그 보정·ATE 자동화**로 임베디드 기반을 쌓았고, 신보에서는 **8채널 시리얼 통신 드라이버(IRST)** 와 **7개 모듈 실시간 통합 운영 SW(NSLR)** 를 맡았습니다. 상위 애플리케이션을 바꿀 수 없을 때 **드라이버에서 끝내는** 방식으로 실장비 납품까지 경험했고, 요구사항이 중간에 바뀌는 상황에서도 **HIL → 1차 납품 → 재설계 → 재납품**까지 수행했습니다.

**계양전기 지원 포인트:** ECU급 **저수준 C · 통신 스택 · HIL · 다채널 동시 통신** — 모터 ECU SW(임베디드·BSW)와 같은 문제 축입니다.

### [1] IRST — 자체 FPGA 통신카드 대체 (Linux Driver · 호환 레이어)

| | |
|---|---|
| **기간** | 2026.01 – 2026.06 |
| **역할** | 호환 레이어 · Linux 드라이버 · 검증 앱 — **단독** |
| **목표** | 상용 카드(tdrv009/002) → 자체 FPGA, **기존 유저 앱 무수정** |

#### 무엇을 했는지

상용 통신카드를 자체 FPGA 카드로 갈아타면서, **드라이버·호환 레이어·검증용 앱**을 처음부터 끝까지 맡았습니다. RS422는 기존 스택이 tty 기반이라 **tty**, HDLC는 **ioctl**로 붙였습니다.

#### 일정

| 시기 | 내용 |
|------|------|
| 1 – 2월 | 상용 드라이버 분석, 상용·자체 **레지스터 맵** 대조 |
| 3월 중순 | 카드 제작 완료 → 베이스보드 장착 → **HIL** (인식·HW제어·맵핑·통신) |
| 3월 | **1차 납품** (당시 절차서 기준) |
| 4 – 6월 | 고객 **앱 스펙** 반영 재작업 → **재납품** (중간 약 2개월 간격) |

> **2026년 1분기** 같은 시기에 **저궤도 운영제어(신규)** 와 **병행** — 두 과제 동시 수행.

#### 통신 사양 (최종 요구)

| 채널 | 프로토콜 | 인터페이스 | 페이로드 | 주기 |
|------|----------|------------|----------|------|
| 7ch | RS422 | tty | 200 byte | 1 Hz |
| 1ch | HDLC | ioctl | 50 byte | 200 Hz |

**8채널 동시 통신**, 채널마다 주기가 다름.

#### 요구 변경 — 이력서 표현

처음엔 **단일 채널 절차서** 기준으로 개발·1차 납품했습니다. 이후 고객 앱 쪽 스펙이 전달되면서 **8채널 동시·이기종 주기** 조건이 추가됐고, 절차서에도 다중 채널 항목이 없어 **드라이버·호환 레이어를 다시 맞췄습니다.** 스펙 전달이 늦었지만, 결과적으로 **다채널 실시간 통신**까지 검증하고 마무리했습니다.

#### 기술 이슈와 대응

- 드라이버 버퍼 **FIFO → 원형 큐**로 변경
- HDLC **0 byte** 간헐 수신, RS422 **분할 수신** 발생
- 상위 앱 **수정 불가** → 드라이버에서 **헤더 기준 패킷 조립·분리**로 처리
- **70시간 이상 연속 가동** 후 납품

#### 성과

- 자체 FPGA 카드 **호환 SW 전량** 구축 및 **납품·재납품** 완료
- 앱 변경 없이 **다채널·이기종 주기** 통신 검증

### [2] NSLR — 차세대 SLR(레이저 거리측정) 운영제어 SW

| | |
|---|---|
| **기간** | 2023.01 – 2025.10 |
| **역할** | 운영제어 **시스템 로직 단독** (Scheduler 제외) / Scheduler **사수** |
| **성격** | **7개 모듈 + 3종 센서** 실시간 통합·현장 운영 (IRST와 **별개**) |

#### 무엇을 했는지

레이저로 우주물체·위성 거리를 재는 시스템의 **운영제어 SW**입니다. 구성품 제어·시간 동기화·지상보정·별보정 연동·관측 시퀀스를 맡았습니다. 시스템 설계가 초안인 과제라, **논문·매뉴얼 보며 운영제어부부터 직접 맞춰** 2년 넘게 현장(TRR)까지 갔습니다.

#### 주요 업무

- 7개 모듈(Ethernet TCP/UDP): 이벤트타이머, 광전자, 레이저, 마운트, 항공탐지, 대기환경, 타과제 외부망 + 카메라 3종
- **NTP/GPS** 시간 동기화, 이벤트 타이머, 20ms급 제어 루프
- 별보정·지상보정 운용 로직, 운영 UI(C#), Python/PostgreSQL 분석, .dll 통합
- Scheduler: 동료 구현, 본인 **인터페이스·타이밍·통합** 가이드
- 거창 현장: **개발 + 실장비 연동 + 관측** 동시 (유지보수만 아님)

#### 성과

- TRR·**납품** 기여, **선임연구원** 승진
- 운영제어부 담당 구간 **단독 수행** (마운트 엔코더 정밀 서브루프·Scheduler 구현 제외)

## 지원 동기 (계양전기 — 약 350자)

MCU 보드(STM32)와 ATE로 시작해, 지금은 Linux **통신 드라이버**와 **다모듈 실시간 통합**을 합니다. IRST에서는 8채널 RS422/HDLC를 HIL·연속가동까지 검증해 **납품**했고, 요구가 바뀌어도 드라이버 쪽에서 맞춰 왔습니다. NSLR에서는 7모듈 통합을 2년 현장까지 끌었습니다. 계양전기 **모터 ECU SW**는 제가 해온 **C · 통신 · HIL · 통합**과 같은 길이라 생각합니다. AUTOSAR BSW·MBD는 입사 후 바로 배우겠습니다.
