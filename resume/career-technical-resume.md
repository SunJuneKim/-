## 3. ㈜신보 (2023.01 – 현재) · 선임연구원

### 3-1. IRST 통신카드 대체 프로젝트 (2026.01 – 2026.06)

**프로젝트 개요**  
SBC + 상용 통신카드(tdrv009, tdrv002) 구성을 **자체 FPGA 통신카드**로 교체. 기존 **유저 애플리케이션 수정 없이** 동작하도록 호환성 확보가 목표.

**담당 역할**  
호환 레이어, Linux 통신 드라이버, 검증용 응용 프로그램 **단독 개발**. (드라이버 코어는 동료 기반, 본인이 레지스터 맵·로직 수정 주도)

**주요 업무**

| 영역 | 상세 |
|------|------|
| 호환 레이어 | 상용·자체 카드 **레지스터 맵·매뉴얼 대조**, API 호환 구현 |
| 통신 스펙 | **RS422 7ch** (200 byte @ 1 Hz, tty) + **HDLC 1ch** (50 byte @ 200 Hz, ioctl) |
| 드라이버 | FIFO → **순환 큐** 구조, HDLC 0-byte 수신·RS422 **분할 RX** 처리 |
| 레거시 대응 | 앱 수정 불가 → **드라이버 헤더 기반 패킷 파싱** |
| 검증 | PC 연동 목업, C#/Python 테스트 앱, **HIL 연동** (3월 1차 납품) |
| 이슈 대응 | 고객 앱 스펙에 다채널 절차 미비 → 4–6월 재작업 후 **2차 납품** |

**성과**

- **8채널 동시** 수신(주기·프로토콜 상이) 안정화
- **70시간 이상 연속 운용** 검증 후 납품 완료
- 저궤도 프로젝트와 **2026.01부터 병행** 수행

**기술 스택:** Linux C (driver), RS422, HDLC, FPGA 통신카드, C#/Python (test)

### 3-2. NSLR — 차세대 SLR 운영제어 SW (2023.01 – 2025.10)

**프로젝트 개요**  
위성 레이저 거리 측정(SLR)을 위한 **차세대 운영제어 플랫폼**. 7개 구성품 + 3종 카메라 실시간 연동.

**담당 역할**  
운영제어부 **시스템 로직 오너** (스케줄러 모듈 제외). 스케줄러는 동료 개발, 본인 **기술 리드(사수)** — 인터페이스·타이밍·통합.

**주요 업무**

| 영역 | 상세 |
|------|------|
| 다모듈 통합 | 이벤트타이머·광전자·레이저·마운트·항공탐지·대기환경·외부망 + 카메라 3종 |
| 시간 동기화 | **NTP/GPS** 기반, ns급 요구 대응 설계·구현·튜닝 |
| 실시간 제어 | **20ms 제어 루프**, 이벤트 타이머, 위성 트래킹 로직 |
| 보정 | **별보정(star calibration)** 운용·로직, closed-loop calibration |
| 현장 | 거창 **2년+ 상주** — 구현·실장비 연동·TRR·납품·관측 운영 병행 |
| 리더십 | 한화 담당자 4회 변경 — 요구 분석·안정화; TRR 촉박 시 **Python 분석 도구** 자발 개발 |

**성과**

- **50 arcsec 이하** 관측 정밀도 달성 기여 (동기화·보정·운영로직 영역)
- 구조 변경 제약 하 **timing jitter** 분석·튜닝으로 운영 안정화
- 4PC 분산 아키텍처(관측/전시/처리/관리), PostgreSQL 운영 DB

**기술 스택:** C#, WinForms, TCP/UDP, NTP/GPS, OpenCV, PostgreSQL, Python

> **이력서 표현:** "우주물체·SLR" 대신 **다모듈 실시간 통합·정밀 제어 플랫폼**으로 일반화

## 7. 자기소개 (경력 서술형, 약 600자)

임베디드 SW 개발자로 **7년 3개월** 경력을 쌓았습니다. 에너시스에서 **STM32·MSP430 펌웨어**, Calibration, Modbus, EMI 인증, **ATE 자동화**로 실무 기반을 다졌고, 아트랩소프트에서 원자력 **SW 검증**을 거치며 요구사항 기반 시험·품질 마인드를 익혔습니다.

신보에서는 **다모듈 실시간 통합**과 **Linux 드라이버** 영역으로 확장했습니다. NSLR에서는 7개 모듈·3종 센서 연동, NTP/GPS 동기화, 20ms 제어 루프, 현장 TRR·납품까지 **시스템 로직 오너**로 수행했습니다. IRST에서는 상용 통신카드를 FPGA 카드로 교체하며 **호환 레이어·드라이버 수정·HIL**을 단독 담당, RS422/HDLC 8채널 동시 통신을 **70시간+ 연속 운용**으로 검증·납품했습니다.

계양전기 **모터 ECU·전장 임베디드 SW**는 제 강점인 **저수준 C·통신·통합·현장 검증**과 방향이 일치합니다. AUTOSAR BSW(Mobilgene)와 MBD는 입사 후 집중 학습할 영역이며, 빠르게 팀에 기여하겠습니다.
