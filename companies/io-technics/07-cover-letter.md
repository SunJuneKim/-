# 이오테크닉스 — 자기소개서 (장비 SW)

> 제출 항목: 자기소개 / 업무 성과 / 문제해결 능력  
> 굵은 글씨·백틱 미사용 · 경력기술서(GUI)와 톤 일치

---

## 1. 자기소개

[HW와 SW를 연결하며 장비의 안정성을 만드는 Embedded·장비 SW 개발자]

7개 실시간 장비를 하나의 운영제어 화면으로 묶고, Linux Driver와 FPGA 통신카드를 직접 다루며 HIL로 70시간 넘게 검증한 경험을 해 온 개발자입니다. 저에게 장비 소프트웨어란 화면만 그리는 일이 아니라, 하드웨어가 실제로 어떻게 움직이는지 이해하고 그 위에 안정적인 제어·모니터링 계층을 올리는 일입니다.

커리어는 MCU 펌웨어에서 시작했습니다. SPI, UART, I2C, RS485, ADC 등 저수준 인터페이스를 구현하며 하드웨어 동작 원리를 익혔고, 4–20mA Calibration·EMI 인증·ATE 자동화까지 장비 개발 초기 단계를 경험했습니다. 이후 원자력 ESF-CCS 계통 SW 검증을 수행하며 IEEE 기준의 요구사항 추적, 단위·통합·시험, 증적 관리를 익혔습니다. 기능만 맞추는 개발이 아니라, 장비가 오래 안정적으로 돌아가게 만드는 품질 관점을 이때부터 가지게 됐습니다.

현재는 C# WPF·WinForms 기반 운영제어 GUI, Linux Device Driver, FPGA 통신카드, 다수 장비 실시간 연동을 맡고 있습니다. 상용 통신카드를 FPGA 카드로 교체할 때는 상위 Application 수정 없이 Driver Layer에서 호환성을 맞췄고, NSLR·저궤도 프로젝트에서는 TCP/UDP로 여러 장비를 묶는 통합 제어 화면과 3D 시각화(Cesium)까지 구현했습니다. 하드웨어 최하단부터 사용자 화면까지 이어지는 구조를 이해해야 장비 SW가 흔들리지 않는다고 봅니다.

저는 새 기술을 빠르게 익히는 것보다, 새 환경에서도 원인을 끝까지 추적하고 시스템 관점에서 해결하는 개발자가 되는 쪽을 더 중요하게 생각합니다. 이오테크닉스에서도 레이저 응용 장비의 HW와 SW를 연결하고, 현장에서 검증 가능한 안정적인 장비 소프트웨어를 만드는 엔지니어로 기여하고 싶습니다.

## 2. 업무 성과 경험

[Legacy Application 수정 0% — Linux Driver 호환 설계 및 HIL 검증]

가장 기억에 남는 성과는 SBC와 상용 통신카드를 FPGA 기반 자체 통신카드로 대체한 IRST 프로젝트입니다. 핵심 제약은 상위 사용자 Application 코드를 단 한 줄도 수정하지 않고, Driver Layer에서 완전한 호환성을 제공해야 한다는 것이었습니다.

상용 Driver와 FPGA Register Map을 정밀 분석하고, Driver Header 기반 Packet Parsing과 ioctl/tty 인터페이스를 구현했습니다. RS422 7채널과 HDLC 통신을 동시에 처리하면서 데이터 병목과 예외가 발생했고, 저수준 구조를 다음과 같이 개선했습니다.

- 버퍼 구조: FIFO를 순환 Queue로 전환해 데이터 손실 방지
- 예외 처리: HDLC Zero-length Packet, RS422 Split RX 분할 수신 로직 구현
- 검증: C#·Python Test Tool을 직접 제작하고, HIL 환경에서 70시간 이상 연속 운용 시험 수행

고객 요구사항 변경이 들어왔을 때도 확장 가능한 Driver 구조를 기반으로 신속히 대응했고, FPGA 통신카드의 안정적인 적용에 기여했습니다. 이 경험을 통해 Driver는 단순한 HW 제어 코드가 아니라, HW 특성을 추상화해 상위 Application과 연결하고 장비 안정성·유지보수성을 좌우하는 핵심 계층임을 배웠습니다. 장비 SW 개발에서도 HW 인터페이스를 정확히 이해할수록 GUI와 제어 로직이 안정된다는 점이 같습니다.

## 3. 문제해결 능력

[집요한 원인 분석과 현장 디버깅으로 시스템 신뢰성을 완수하는 엔지니어]

복잡한 임베디드 환경과 현장 변수 속에서도 끝까지 원인을 규명하고 해결책을 구현하는 것이 저의 강점입니다.

2년 이상 현장에 상주하며 다중 실시간 장비를 연동하는 운영제어 시스템을 개발할 때, 구조적 제약 속에서 Timing Jitter로 인한 불안정 문제가 있었습니다. Python 기반 Timing 분석 도구를 직접 만들어 데이터 패턴을 추적했고, NTP/GPS 시간 동기화와 20ms 제어 Loop 튜닝으로 관측 정밀도 50 arcsec 이하를 안정화했습니다. 담당자가 여러 차례 바뀌는 상황에서도 장비 인터페이스 규격과 요구사항을 재정리해 실장비 통합 시험과 TRR까지 완료했습니다.

최근 IRST 프로젝트에서도 같은 방식으로 접근했습니다. RS422 Split RX, HDLC Zero-length Packet 같은 저수준 예외를 Driver에서 처리하고, 직접 만든 Test Tool로 HIL 70시간 무중단 검증을 이끌었습니다. 문제가 생기면 로그와 현상부터 좁혀 가고, 구조를 바꿀 수 없을 때는 측정·분석·튜닝으로 풀며, 필요하면 검증 도구를 직접 만듭니다.

앞으로도 HW-SW 경계에서 발생하는 이슈를 끝까지 분석해 장비 완성도를 높이는 개발자가 되겠습니다.

7개 실시간 장비 통합 제어 GUI, Linux Driver·FPGA 통신카드, HIL 70시간 검증까지 수행한 장비 SW 개발자입니다. MCU 펌웨어(SPI/UART/RS485·Calibration)에서 출발해 C# WPF 운영제어, Driver 호환 설계, 3D 시각화(Cesium)까지 HW 최하단부터 UI까지 이어지는 개발을 해 왔습니다. ESF-CCS SW 검증으로 요구사항 기반 시험·품질 관점도 익혔습니다. 이오테크닉스에서 레이저 응용 장비의 안정적인 제어·모니터링 SW에 기여하겠습니다.

### 업무 성과 (약 400자)

상용 통신카드→FPGA 카드 교체 시 Application 무수정 조건에서 Driver Layer 호환을 구현했습니다. Register Map 분석, 순환 Queue, HDLC·RS422 예외 처리, C#/Python Test Tool·HIL 70시간 연속 시험으로 납품 완료. 장비 SW에서 HW 인터페이스를 정확히 이해할수록 제어 화면과 시스템이 안정된다는 경험을 얻었습니다.

### 문제해결 (약 400자)
